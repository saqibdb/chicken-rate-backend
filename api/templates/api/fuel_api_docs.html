Fuel Prices API

Fuel app endpoints. Base URL: {{ base_url }}

Latest saved prices

GET prices/current/ returns the latest effective date with petrol and diesel fields.

Fetch latest provider prices

GET prices/fetch/ reads both fuels from the provider and saves them in the row for each effective date. At the admin-configured FUEL_DAILY_PRICE_FETCH_TIME, the backend fetches and saves the latest prices, then sends fuel app devices a push notification containing both prices and their changes. The schedule uses the configured Asia/Karachi time zone.

Read saved history

GET prices/history/ returns the newest combined rows, with both fuels on each effective-date row when available. limit defaults to 30 and accepts 1–365. Example: GET prices/history/?limit=90.

Import daily provider history

GET prices/history/import/?fuel=petrol&limit=30 or GET prices/history/import/?fuel=diesel&limit=30. Each call saves that fuel into a row keyed by effective date, merging with the other fuel when present. limit accepts 1–365 and defaults to 30.

Register a fuel app device

POST devices/register-push/ with JSON fields device_id, fcm_token, and optionally device_name, platform, app_version, os_version.

Send push notification

Use Fuel push notifications in Django Admin and select Send fuel push notification. Delivery uses the independent FUEL_FIREBASE_SERVICE_ACCOUNT_JSON credential.
